# Normandie-Reise-App – native Android-App

Native Android-App ohne WebView.

## Enthalten

- feste Startadresse: Lindenstraße 57, 02979 Tätzschwitz, Elsterheide
- Anreise Tag 1 und Tag 2
- einzelne Navigationsetappen
- Sandstrände, Küstenorte und Angelstellen
- Familienziele und Versorgung
- Suche und Kategorien
- lokal gespeicherte Favoriten
- Übergabe an Google Maps oder eine andere Karten-App

## APK automatisch bauen

1. Alle Dateien dieses Projekts in das GitHub-Repository hochladen.
2. In GitHub den Reiter **Actions** öffnen.
3. Den Workflow **Build Android APK** auswählen.
4. **Run workflow** drücken.
5. Nach erfolgreichem Lauf das Artefakt **Normandie-Reise-App** herunterladen.
6. ZIP entpacken und `app-debug.apk` auf dem Android-Handy installieren.

Beim ersten manuellen Installieren kann Android die Freigabe „Unbekannte Apps installieren“ für den Browser oder Dateimanager verlangen.
